## P0：隐私与可靠性

- [x] Windows 使用当前用户 DPAPI 文件保存小米 Cookie、数据密钥、历史密钥与远程 API Token；环境变量仅作为显式优先回退。
- [ ] macOS Keychain 生产验证与 Android Keystore 凭证适配。现有 macOS 实验代码保留，但按当前迭代要求暂停，不作为已支持平台发布。
- [x] 历史存储支持 scrypt + AES-256-GCM、明文自动迁移、原子替换和错误密钥保护。
- [x] 支持删除单个 Terra 历史版本和清理单篇全部历史，并保持原子加密写入。
- [x] 将历史升级为可查询 SQLite，正文/标题/笔记 ID 使用行级 AES-GCM 与 HMAC 查询键；兼容迁移旧明文/加密 JSON。
- [x] 增加历史归档入口、删除前快照标识和从任意快照重建新笔记。
- [x] 增加 Terra 笔记收藏、归档、标签和隐私级别元数据。
- [x] 抽取通用加密 JSON Store，支持迁移、串行更新、原子替换和错误密钥保护。
- [x] 增加内存脱敏审计、连续失败熔断和只读安全模式；审计不记录正文、Cookie、路径或原始笔记 ID。
- [x] 读取小米文件夹并支持按文件夹筛选。
- [x] 检测富文本，并在正文未变化时让标题修改保留上游原始 content。
- [x] 建立脱敏抓包证据矩阵，明确已证明操作、仅读字段和未证明写入；详见 `docs/XIAOMI_CAPTURE_EVIDENCE.md`。
- [ ] 取得真实操作证据后，再增加富文本正文无损编辑、附件、文件夹写操作、置顶和提醒；当前禁止猜测上游接口。

## P2：RAG

- [x] 文本、Markdown、JSON、CSV 与 Resource 接入、清洗、重叠分块、内容哈希去重和敏感信息检测。
- [x] 本地稀疏向量与 BM25 混合检索、编号引用、增量重建和删除传播。

## P0：最终安全与运维

- [x] API 默认仅绑定 `127.0.0.1`，远程绑定要求显式开关与至少 32 字符 Token。
- [x] Origin/跨站写入拦截、远程 Token 恒定时间比较与安全响应头。
- [x] 10 类服务端数据文件（含 Resource 游标/冲突状态与旅行附件 SQLite）的离线加密导出、校验、确认恢复、预恢复备份和失败整体回滚。
- [x] `.env`、DPAPI 凭证、Cookie 与主密钥不进入数据备份，备份恢复文档明确密钥恢复边界。
- [x] 30 文档 RAG 加密负载回归：写入、首次检索、并发缓存查询与机密默认排除。
- [x] 浏览器本地 Todo 与 UI 偏好使用 PBKDF2 + AES-256-GCM 独立导出/恢复、白名单校验、恢复前快照和写入回滚。
