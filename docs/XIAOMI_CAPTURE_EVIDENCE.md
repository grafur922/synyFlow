本文件只记录脱敏后的接口形态和字段统计，不包含 Cookie、正文、笔记 ID、分页游标、文件夹 ID 或其他原始值。原始抓包目录已被 `.gitignore` 排除，不应提交、分享或进入备份。

## 已证明的操作

| 能力 | 已观察请求 | Terra 状态 |
| --- | --- | --- |
| 分页读取笔记与文件夹 | `GET /note/full/page` | 已接入，包含游标完整性和缓存边界 |
| 读取笔记详情 | `GET /note/note/{id}/` | 已接入 |
| 创建普通笔记 | `POST /note/note` | 已接入，创建后再执行已证明的更新流程 |
| 更新普通笔记 | `POST /note/note/{id}` | 已接入，写前保存 Terra 历史 |

上述结论来自 22 条 2026-07-12 的请求/响应记录。所有记录均返回 HTTP 200，但 Terra 仍同时校验 HTTP 状态、业务 `result`、业务 `code` 和 `data`，不能只以 HTTP 200 判断成功。

## 暂不实现的上游写能力

- 富文本样式、清单、图片和其他附件的无损写入。
- 创建、重命名、删除文件夹，以及把笔记移动到非根文件夹。
- 置顶、取消置顶、设置提醒和清除提醒。
- 永久删除；当前只证明 `purge=false` 的软删除。

在取得对应操作的成对请求/响应、失败响应和冲突样本前，不根据字段名猜测接口。新抓包应使用测试笔记和测试文件夹，并在完成后撤销会话。

## 当前保护边界

- 连接器只访问固定的 `https://i.mi.com` 源，限制响应大小和请求时长。
- Cookie 只由服务端凭证层读取，不进入前端、日志、审计和 Terra 数据备份。
- 写操作串行执行，并在更新、恢复和软删除前建立 Terra 本地加密历史。
- 富文本笔记在正文未变化时保留上游原始 `content`；修改正文会降级为已证明的普通文本结构，界面必须保留警告。
- 上游冲突、凭证失效、连续失败熔断、只读模式和分页异常均显式失败，不静默覆盖或猜测重试。
